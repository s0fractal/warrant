# Reviews — inbound

Reviews **of this project, by others**. Each `-response` file is our reply,
kept beside the review rather than folded into it, so that what was said and
what we did about it stay separable.

Every reviewer here has been a language model run by this project's own
operator. That is defect-hunting, not an independent gate, and it is why the
distinction gets restated wherever a count of reviews appears. Two of these
found real defects; the fixes are credited in the commits that made them.

Reviews written **by** this project **of** other people's specifications live in
[`../reviews-outbound/`](../reviews-outbound/). They are the opposite direction
and are kept apart so that neither can be mistaken for the other.

# Licensing — this paper vs. the code it documents

Two surfaces, two licences. This file separates them so neither is mistaken for
the other.

## The paper

`references.bib`, and the figures/text of this directory that constitute the
written work — is licensed under **Creative Commons Attribution 4.0
International (CC BY 4.0)**.

<https://creativecommons.org/licenses/by/4.0/>

You may share and adapt it, including commercially, with attribution to
Serhii Glova and a link to the licence.

## The code and the repository

Everything else in the Warrant repository — the specification, all
implementations (`impl/`, `impl-go/`, `impl-rs/`), tools, tests, conformance
pack, proofs, and `check_claims.py` in this directory (which is build tooling,
not the paper) — remains under the repository's **MIT** licence, unchanged.

See the repository root `LICENSE` for the MIT text. A CC BY paper documenting
MIT code is a deliberate split: the prose is meant to be quoted and reused with
credit; the software is meant to be used and modified with minimal restriction.

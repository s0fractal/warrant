# Triage of the 2026-10-16 DeepReview

Review: [`2026-10-16-deepreview.md`](2026-10-16-deepreview.md), verbatim. It was
run on `paper.md` as deposited in v1.0.0, which is unchanged since `d83984f`.

Each point is checked against the repository before it is acted on. A
reviewer's description of the code is a hypothesis until the code agrees, and
so is the paper's. Dispositions:

- **CODE**: a defect or gap in the artifact. Fixed in code or vectors first; the
  paper follows.
- **TEXT**: the artifact already does the right thing and the paper does not
  say so, or says it imprecisely.
- **RELATED**: missing prior art.
- **NO**: does not hold, with the reason.
